# Business Components 业务组件

::: warning ⚠️ 注意
本模块包含的组件与特定业务系统（如 ERP、CRM 等）强耦合。

- 依赖特定的后端接口规范（如 `/core/assDialog`）。
- 包含部分写死的业务逻辑（如字段映射、状态处理）。
- **不可** 在脱离业务上下文的环境中单独使用。
:::

## 介绍

这些组件通常是基于通用基础组件 (`@ui`) 的二次封装，旨在提高特定业务场景下的开发效率。它们封装了复杂的业务逻辑、数据获取和状态管理，使得业务开发者可以通过简单的配置即可使用。
