# I18n 国际化

基于 `vue-i18n` 封装的国际化解决方案，支持多语言切换、自动适配 UI 组件库（Arco Design、VxeUI）等功能。

## 引入
 
核心功能位于 `@utils` 包中。

```ts
import { setupI18n, t, setLocale, currentLocale, onLocaleChange } from '@utils';
```

## 初始化 (main.ts)

在应用入口文件中初始化 i18n。

```ts
import { createApp } from 'vue';
import { setupI18n } from '@utils';
import App from './App.vue';
import zhCN from './locales/zh-CN';
import enUS from './locales/en-US';

const app = createApp(App);

setupI18n(app, {
  locale: 'zh-CN', // 默认语言
  legacy: false,   // 使用 Composition API 模式
  messages: {
    'zh-CN': zhCN,
    'en-US': enUS
  }
});

app.mount('#app');
```

## 使用方法

### 在组件中使用 (Script Setup)

```vue
<script setup lang="ts">
import { t, setLocale, currentLocale } from '@utils';

const toggleLang = () => {
  setLocale(currentLocale.value === 'zh-CN' ? 'en-US' : 'zh-CN');
};
</script>

<template>
  <div>
    <h1>{{ t('hello') }}</h1>
    <button @click="toggleLang">切换语言 / Switch Language</button>
  </div>
</template>
```

### 响应式语言切换

使用 `<a-config-provider>` 配合 `@kunkka/ui` 提供的 `useArcoLocale` 可以实现 Arco Design 组件的语言切换。

```vue
<script setup lang="ts">
import { useArcoLocale } from '@kunkka/ui';

const { locale } = useArcoLocale();
</script>

<template>
  <a-config-provider :locale="locale">
    <router-view />
  </a-config-provider>
</template>
```

### VxeUI / vxe-table 适配

`@kunkka/ui` 内部已经处理了 VxeUI 的语言切换监听。只要调用了 `@utils` 的 `setLocale`，VxeUI 的语言会自动同步，无需额外配置。

## API

### setupI18n(app, options)

初始化 i18n 实例。

- `app`: Vue 应用实例
- `options`: vue-i18n 的初始化选项

### t(key, ...args)

翻译函数，等同于 vue-i18n 的 `t`。

### setLocale(locale)

切换当前语言。

- `locale`: `'zh-CN' | 'en-US' | ...`

### currentLocale

当前语言的 Ref 对象（只读）。

### onLocaleChange(callback)

注册语言切换的回调函数。

```ts
onLocaleChange((locale) => {
  console.log('Language changed to:', locale);
});
```
