# I18n 国际化

`@sunny-base-web/locales` 是一个基于 `vue-i18n` 封装的国际化模块，提供了统一的初始化流程、动态加载语言包以及类型支持。

## 功能特性

- 📦 **开箱即用**：封装了 `vue-i18n` 的初始化逻辑，内置了基础配置。
- 🚀 **动态加载**：支持异步按需加载语言包，优化应用首屏体积。
- 🛠 **自动扫描**：内置 `loadLocalesMapFromDir` 工具，可根据目录结构自动生成语言包映射。
- 🔌 **高扩展性**：支持合并业务层和第三方组件库（如 Arco Design）的语言包。

## 安装

该包支持两种使用方式：作为 Monorepo 内部包使用，或通过 npm 安装使用。

### 方式一：Monorepo Workspace

在 Monorepo 项目内部（如 `apps` 目录下的应用），推荐通过 workspace 协议引用，以确保使用的是本地最新代码：

```json
{
  "dependencies": {
    "@sunny-base-web/locales": "workspace:*"
  }
}
```

### 方式二：NPM 安装

该包也发布到了 npm Registry，如果是在外部独立项目中使用，可以通过 npm 命令安装：

```bash
npm i @sunny-base-web/locales
```

### 切换说明

- **开发阶段**：在 Monorepo 环境下开发时，请务必使用 `workspace:*` 协议，这样修改 `@locales` 包的代码会实时生效，无需重新构建发布。
- **独立使用**：如果你将该包发布到私有或公共 npm 仓库，并在其他独立项目中使用，请使用标准的版本号依赖。

## 快速上手

### 1. 组织语言文件

建议在项目中创建 `src/locales` 目录，并推荐按照 `langs/{lang}/{module}.json` 的结构组织语言文件。

目录结构示例：
```text
src/locales/
├── langs/
│   ├── en-US/
│   │   ├── common.json
│   │   └── sys.json
│   └── zh-CN/
│       ├── common.json
│       └── sys.json
└── index.ts
```

### 2. 封装初始化逻辑

在 `src/locales/index.ts` 中，使用 `loadLocalesMapFromDir` 扫描文件，并定义 `loadMessages` 钩子。

```typescript
import type { App } from 'vue';
import type { LocaleSetupOptions, SupportedLanguagesType } from '@sunny-base-web/locales';
import { 
  setupI18n as coreSetup, 
  loadLocalesMapFromDir 
} from '@sunny-base-web/locales';

// 使用 Vite 的 import.meta.glob 扫描语言文件
const modules = import.meta.glob('./langs/**/*.json');

// 解析模块路径，生成 { [locale]: loaderFn } 映射
// 正则表达式需匹配出两个分组：语言标识 (如 zh-CN) 和 模块名 (如 common)
const localesMap = loadLocalesMapFromDir(
  /\.\/langs\/([^/]+)\/(.*)\.json$/,
  modules,
);

/**
 * 加载语言包的钩子函数
 * @param lang 目标语言
 */
async function loadMessages(lang: SupportedLanguagesType) {
  // 并行加载：
  // 1. 应用自身的语言包
  // 2. 第三方库的语言包（如果需要）
  const [appLocaleMessages] = await Promise.all([
    localesMap[lang]?.(),
    // loadThirdPartyMessage(lang), 
  ]);
  
  // 返回应用语言包的 default 导出
  return appLocaleMessages?.default;
}

export async function setupI18n(app: App, options: LocaleSetupOptions = {}) {
  await coreSetup(app, {
    defaultLocale: 'zh-CN', // 默认语言
    loadMessages,           // 传入加载函数
    missingWarn: import.meta.env.DEV, // 开发环境开启缺失警告
    ...options,
  });
}
```

### 3. 在应用入口注册

在 `main.ts` 中调用封装好的 `setupI18n`：

```typescript
import { createApp } from 'vue';
import { setupI18n } from './locales';
import App from './App.vue';

const app = createApp(App);

async function bootstrap() {
  // 初始化国际化配置
  await setupI18n(app);
  
  app.mount('#app');
}

bootstrap();
```

## 使用指南

### 在组件中使用

使用 `vue-i18n` 提供的 `useI18n`：

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n';

const { t } = useI18n();
</script>

<template>
  <!-- 使用 t 函数 -->
  <div>{{ t('sys.login.title') }}</div>
  
  <!-- 在模板中直接使用全局 $t -->
  <div>{{ $t('common.ok') }}</div>
</template>
```

### 切换语言

使用 `@sunny-base-web/locales` 导出的 `loadLocaleMessages` 方法进行切换，它会自动处理语言包的加载和合并。

```typescript
import { loadLocaleMessages } from '@sunny-base-web/locales';

// 切换到英文
await loadLocaleMessages('en-US');

// 切换到中文
await loadLocaleMessages('zh-CN');
```

## API 参考

### `setupI18n`

核心初始化函数。

```typescript
function setupI18n(app: App, options?: LocaleSetupOptions): Promise<void>
```

**LocaleSetupOptions 配置项**:

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `defaultLocale` | `SupportedLanguagesType` | 默认语言，默认为 `zh-CN` |
| `loadMessages` | `LoadMessageFn` | 异步加载语言包的回调函数，需返回要合并的消息对象 |
| `missingWarn` | `boolean` | 是否在控制台打印缺失 Key 的警告 |

### `loadLocalesMapFromDir`

辅助工具：从目录结构生成语言包加载映射。

```typescript
function loadLocalesMapFromDir(
  regexp: RegExp,
  modules: Record<string, () => Promise<unknown>>
): Record<Locale, ImportLocaleFn>
```

- **regexp**: 用于解析文件路径的正则表达式。必须包含两个捕获组：
  1. `locale`: 语言代码 (如 `zh-CN`)
  2. `fileName`: 模块/文件名 (如 `common`)，将作为翻译 Key 的前缀。
- **modules**: `import.meta.glob` 返回的模块对象。

### 导出成员

模块直接导出了以下常用对象：

- `$t`: 全局翻译函数 (Composition API 之外使用)
- `i18n`: Vue I18n 实例
- `useI18n`: `vue-i18n` 的 hook
- `SupportedLanguagesType`: 支持的语言类型定义
